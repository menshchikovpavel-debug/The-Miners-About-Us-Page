# About us — интерактивная демка страницы

Папка: `Web/Assets/About Us_Demo_V2` · Обновлено: 25.11.2026 (вечер)

## Задача
Кликабельный прототип страницы About us для сайта The Miners. Один адаптив на десктоп и телефон, без сборки и зависимостей — открывается как `index.html`. Собрана по фрейму Figma `5422-41` (1512) файла `h3azJgJDywcmPuLuxt8hcf`.

Живёт на GitHub Pages: **menshchikovpavel-debug.github.io/The-Miners-About-Us-Page/**

## Люди
Павел — заказчик и приёмка. Основатели на фото в секции story: Егор Колпаков и Oldřich Valta.

## Решения
- Все значения берутся из коллекций переменных Figma: Color, Corner Radius, Stroke Weight, Button padding, Typography (Kegel). Своих значений в таблице стилей нет.
- Kegel — **два фиксированных режима**, не плавный диапазон. Ниже 760 подставляется мобильная колонка. Если заголовок не влезает, он шагает вниз по лестнице `--ladder`, а не ужимается коэффициентом.
- Акцент — чёрный `#141414`. Секции с цифрами и цитатами на чёрном, текст белый.
- Заголовки секций — 48/90 по фрейму. В новой таблице 48 на десктопе — это **H4, Large subtitle**.
- Таймлайн — скролл-лист с живой рельсой. Четыре варианта сотрудничества — револьверный барабан.
- 25.11 — вертикальный ритм **иерархичный**, а не плоский: `--pad-sec` (поле секции) > `--sp-1` (между блоками) > `--sp-2` (внутри группы). Десктоп 100 / 56 / 32, телефон 56 / 32 / 16. Первая попытка выровнять всё в одно значение была ошибкой — поле секции стало меньше нахлёста `--lap` и визуально ушло в минус.
- 25.11 — Kegel обновлён по новой таблице из 12 стилей: Large Display 288/360, Display 152/184, H1 96/120, H2 64/96, H3 48/64, H4 40/48, H5 24/32, H6 20/24, Body 16/20, Caption 10/13, Button 16/20, Big Button 20/24.
- 25.11 — на телефоне цифры **не уменьшаются** при скролле, панель не сжимается (ранее было два состояния — Павел попросил оставить крупные).
- 25.11 — Big Button это десктопный размер; на телефоне кнопка берёт обычный Button (24×16, кегль 16).
- 25.11 — кнопки без пилюли: в Corner Radius есть только 4 / 16 / 40, взят Regular 4.
- 25.11 — нахлёст секций `--lap` = `--r-sec` (40): скруглённая секция перекрывает нижнюю на весь радиус, зазоров в углах нет.
- 25.11 — поле секции = боковому отступу: `--pad-sec: var(--gut)` (80 десктоп / 32 телефон). Нижний паддинг `calc(--pad-sec + --lap)` — следующая секция съедает нахлёст, видимое поле остаётся равным боковому. Иерархия внутри: телефон 32 / 24 / 14, десктоп 80 / 56 / 32.
- 25.11 — **мобильные значения берутся из мобильных фреймов Figma** (`About us_Mobile` 5240:2181, `Academy_Mobile` 4250:1810): боковая сетка **24**, не 32. Там же видно, что цифры стоят на 24 ниже хедера, шаг между ними 80, Display 152.
- 25.11 — на телефоне `--r-sec = var(--r-card)` (16): 40 читалось слишком круглым. Нахлёст `--lap` всегда равен `--r-sec`.
- 25.11 — **правило вертикального ритма (итог)**: поле секции одинаковое сверху и снизу, и **ни один спейсинг внутри секции не может быть больше этого поля**. Телефон 40/40 (`--pad-sec`, `--pad-sec-b`), десктоп 80/80. Потолок спейсингов: `--sp-1` 40 / 56, дальше меньше. В `.sec` снизу `calc(--pad-sec-b + --lap)`, потому что нахлёст съедает --lap. Путь к этому правилу был долгий (сначала «сверху = сбоку», потом «снизу больше всех») — держаться последней формулировки.
- 25.11 — панель цифр на телефоне **не липкая и по содержимому** (`position:static; height:auto`): при 100svh остаток высоты раздувал промежутки между цифрами. Поле сверху = боковому (24).
- 25.11 — мелочи, которые легко поймать снова: `.story__txt p` бьёт `.story__founders` по специфичности (0,1,1 против 0,1,0) и возвращает лишний margin-bottom; `.drum__stick` держит `--hdr-solid` сверху ради липкого состояния, поэтому на телефоне весь `#drum` подтянут вверх на эту же высоту; `SLOGAN_STEPS` в app.js должен содержать только кегели из таблицы (48 / 40).
- 25.11 — цитаты прессы — **шашки**: секция поделена невидимой стеной пополам, нечётная цитата в левой половине, следующая строкой ниже в правой. `grid-row` и `grid-column` проставляет сборщик в app.js, так что порядок не зависит от числа цитат. До этого пробовали три колонки, потом дивайдеры, потом вертикальный барабан — не зашло ничего, шашки Павел принял.
- 25.11 — большая кавычка в углу — 46vh (было 100vh). `overflow:hidden` на `#press` сейчас не нужен, и давать его нельзя, если внутри появится `position:sticky` — секция станет скролл-контейнером и липкость сломается.
- 25.11 — `.tlist__t:first-of-type` не срабатывает: первым DIV внутри `.tlist` лежит рельса `.tlist__bar`, поэтому первый год получал лишнюю линию и отступ. Нужен `.tlist__bar + .tlist__t`.
- 25.11 — у одинокого последнего логотипа (padel powers) только боковой дивайдер, нижнего нет.
